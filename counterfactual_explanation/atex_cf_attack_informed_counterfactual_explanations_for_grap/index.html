    ATEX-CF: Attack-Informed Counterfactual Explanations for Graph Neural Networks¶

    Zhang, Y., Yang, S. B., Khan, A., & Akcora, C. G. (2026). ICLR 2026 Poster.

    🔗 https://openreview.net/forum?id=J1NITEU3Ng

    Motivation¶

    기존의 Counterfactual explanation 방법들은 주로 엣지 삭제(edge deletions)에 집중하여 모델의 취약점을 드러내는 데 한계가 있었습니다. 반면, adversarial attack 기법들은 엣지 추가(edge additions)를 통해 모델을 교란하는 데 효과적인 방법들을 개발해왔습니다. 이 두 영역의 잠재적 시너지를 활용할 필요가 있었습니다.

    Problem / Task Definition¶

    그래프 신경망(GNN)의 예측을 바꾸기 위한 최소한의 변화를 찾는 Counterfactual explanation을 생성하는 문제. 이는 기존의 엣지 삭제 방식만으로는 충분하지 않으며, 엣지 추가를 포함한 더 포괄적인 접근이 필요합니다.

    Key Idea¶

    Adversarial attack 기법에서 사용되는 엣지 추가 전략을 Counterfactual explanation 생성에 통합하여, 더 효과적이고 현실적인 설명을 생성하는 프레임워크를 제안합니다.

    Method¶

    1. Adversarial attack 기법과 Counterfactual explanation 생성 간의 이론적 연결을 수립합니다.
    2. 엣지 삭제와 엣지 추가를 동시에 활용하는 하이브리드 Counterfactual 프레임워크(ATEX-CF)를 설계합니다.
    3. Adversarial attack의 효율적인 탐색 메커니즘을 활용하여 탐색 공간의 복잡성을 줄입니다.
    4. 설명의 충실도(fidelity), 간결성(sparsity), 현실성(plausibility)을 제약 조건 하에서 최적화합니다.

    Contribution¶

    • Adversarial attack과 Counterfactual explanation을 통합하는 이론적 기반을 처음으로 제시했습니다.
    • 엣지 삭제와 엣지 추가를 모두 활용하는 새로운 하이브리드 Counterfactual 프레임워크(ATEX-CF)를 개발했습니다.
    • Adversarial attack의 효율성을 활용하여 Counterfactual 탐색의 복잡성을 줄이고 제어 가능성을 높였습니다.
    • 실험을 통해 제안된 방법이 설명력을 향상시키고 현실적인 설명을 생성함을 입증했습니다.

    Result¶

    제안된 ATEX-CF는 기존 방법 대비 설명력을 향상시키고, 의미론적 타당성을 유지하며, 계산 부담을 줄이는 것으로 나타났습니다.
