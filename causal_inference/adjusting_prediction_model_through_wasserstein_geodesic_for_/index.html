    Adjusting Prediction Model Through Wasserstein Geodesic for Causal Inference¶

    Yan, Y., Yang, H., Chen, Z., Chen, W., Cai, R., & Hao, Z. (2026). ICLR 2026 Poster.

    🔗 https://openreview.net/forum?id=pYLoHuLV45

    Motivation¶

    기존의 인과 추론 방법들은 분포 불균형을 해결하기 위해 공변량(confounders)을 조정하여 균형 잡힌 표현을 학습하지만, 이 과정에서 결과 예측에 필요한 정보가 제거되는 과도한 균형(over-balancing) 문제가 발생할 수 있습니다. 이는 예측 모델의 일반화 성능을 저하시킵니다.

    Problem / Task Definition¶

    인과 추론에서 공변량 분포의 불균형으로 인해 예측 모델이 한 그룹에서 학습한 결과를 다른 그룹에 일반화하기 어렵습니다. 이는 과도한 균형 문제로 인해 예측 정보 손실이 발생할 수 있습니다.

    Key Idea¶

    Wasserstein geodesic을 사용하여 제어 그룹과 처리 그룹 간의 중간 그룹들을 생성하고, 이를 통해 예측 모델을 점진적으로 조정하여 과도한 균형 문제를 피하고 일반화 성능을 향상시킵니다.

    Method¶

    1. Wasserstein geodesic을 이용하여 제어 그룹과 처리 그룹 사이에 여러 중간 그룹들을 생성합니다.
    2. 생성된 중간 그룹들을 사용하여 제어 그룹에서 처리 그룹으로 예측 모델을 점진적으로 조정합니다.
    3. 점진적 조정 과정에서 고품질 샘플을 선택하기 위해 데이터 필터링을 수행합니다.
    4. 조정된 예측 모델을 사용하여 인과 효과를 추정합니다.

    Contribution¶

    • Wasserstein geodesic 기반의 중간 그룹 생성 방법을 제안하여 그룹 간의 부드러운 전환을 가능하게 합니다.
    • 중간 그룹을 활용한 점진적 예측 모델 조정을 통해 과도한 균형 문제를 회피하고 일반화 성능을 향상시킵니다.
    • 데이터 필터링 기법을 도입하여 학습에 사용되는 샘플의 품질을 높입니다.
    • 제안된 방법의 효과 추정 오차에 대한 이론적 분석을 제공합니다.

    Result¶

    여러 벤치마크 데이터셋에서 제안된 방법의 효과성을 입증했습니다.
